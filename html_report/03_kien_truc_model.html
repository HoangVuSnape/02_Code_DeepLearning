📄 03 · Kiến trúc Model

🧠 Kiến trúc chi tiết — từng khối là gì, lấy cảm hứng từ đâu, làm gì

Multimodal VQA-RAD: ảnh + câu hỏi → sinh answer token-by-token. Mỗi khối kèm: cảm hứng (paper) · là gì · làm gì · sơ đồ khối · input/output. Cuối cùng: Reinforcement Learning.
✅ Hướng đã chốt: Generative VQA. Decoder là GRU sinh chuỗi (khối ⑩) + cross-attention, KHÔNG phải MLP classifier. Đề cương đầy đủ: 02_de_cuong_generative_medvqa.html. Khối ⑨ Gated attention chỉ còn là tùy chọn phụ; "decoder attention" chính thức = cross-attention ở khối ⑩.

0 Toàn cảnh — input đến output

Hai nhánh (ảnh, text) → hợp nhất → phân loại thành 1 answer. Màu ■ ảnh · ■ text · ■ fusion.

Input
image [B,3,224,·] + question tokens [B,32]
Output
logits [B,T,V_answer] → greedy/beam → answer string

① CustomCNN image encoder

💡 Cảm hứng: ConvNet cổ điển kiểu LeNet / VGG (LeCun 1998, Simonyan & Zisserman 2014) — chồng các khối Conv → ReLU → Pool để trích đặc trưng không gian, thêm BatchNorm (Ioffe & Szegedy 2015) cho ổn định.
Là gì
CNN tự viết 3 tầng, nhẹ (~vài trăm nghìn tham số), train từ đầu.
Làm gì
Biến ảnh y khoa thành 1 vector đặc trưng thị giác cố định 128 chiều.
Input
ảnh [B, 3, 224, 224]
Output
v_img [B, 128] (đã LayerNorm)

② ResNet-18 (đóng băng) image encoder

💡 Cảm hứng: ResNet (He et al., CVPR 2016) — residual/skip connection cho phép mạng rất sâu. Ở đây dùng theo hướng transfer learning / frozen feature extractor: lấy backbone đã pretrain ImageNet làm "mắt" sẵn có, chỉ học lớp chiếu.
Là gì
ResNet-18 pretrained, bỏ 2 lớp cuối (avgpool+fc), đóng băng toàn bộ (không cập nhật gradient, BatchNorm chạy running-stats).
Làm gì
Trích đặc trưng ảnh mạnh sẵn có → chỉ train lớp Linear(512→128) để đưa về đúng chiều v_img. Dùng ở nhóm C để so với CNN tự viết.
[B,3,224,224] → resnet18.features (đóng băng) → [B,512,7,7]
             → (SE-block? trên 512) → AdaptiveAvgPool → [B,512]
             → Linear(512→128) → LayerNorm → v_img [B,128]
Input
ảnh [B,3,224,224], chuẩn hóa ImageNet
Output
v_img [B,128] · chỉ Linear+LN được train

③ SE-Block — Channel Attention

💡 Cảm hứng: Squeeze-and-Excitation Networks (Hu, Shen, Sun — CVPR 2018). Ý tưởng: không phải kênh feature nào cũng quan trọng như nhau → học trọng số cho từng kênh.
Là gì
Khối attention theo kênh, gắn sau feature map của CNN/ResNet.
Làm gì
"Squeeze" (nén không gian bằng GAP) → "Excite" (2 lớp FC học trọng số 0–1) → nhân lại từng kênh → khuếch đại kênh hữu ích (cạnh, đốm mờ, texture xương), nén kênh nhiễu.
Input
feature map [B, C, H, W]
Output
feature map cùng shape, đã nhân trọng số kênh

④ BiLSTM text encoder

💡 Cảm hứng: LSTM (Hochreiter & Schmidhuber, 1997) giải bài toán gradient tiêu biến của RNN nhờ cổng nhớ; Bidirectional RNN (Schuster & Paliwal, 1997) đọc câu cả 2 chiều để mỗi từ thấy ngữ cảnh trước & sau.
Là gì
Embedding + 1 lớp LSTM 2 chiều (hidden 32 mỗi chiều → 64).
Làm gì
Mã hóa câu hỏi thành vector ngữ nghĩa 64 chiều theo trình tự từ. Không attn: lấy hidden cuối 2 chiều; có attn: dùng Temporal Attention (khối ⑥).
tokens [B,32] → Embedding(V,64,pad=0) → [B,32,64]
             → BiLSTM(64→32×2) → outputs [B,32,64], (h→,h←)
   không attn: v_txt = cat(h→cuối, h←đầu) [B,64]
   có attn:   v_txt = TemporalAttention(outputs) [B,64]
             → LayerNorm → v_txt [B,64]
Input
tokens [B,32] (id từ, pad=0)
Output
v_txt [B,64]

⑤ Transformer Encoder text encoder

💡 Cảm hứng: "Attention Is All You Need" (Vaswani et al., NeurIPS 2017) — self-attention cho mọi từ "nhìn" mọi từ cùng lúc, không cần đệ quy. Dùng làm nhánh so sánh với BiLSTM.
Là gì
Embedding + positional encoding + 2 lớp TransformerEncoder (d=64, 4 head, feed-forward 128).
Làm gì
Mã hóa câu hỏi bằng self-attention song song; gộp các token thành 1 vector 64 chiều bằng masked-mean (không attn) hoặc attention pooling (có attn).
tokens [B,32] → Embedding + Positional [B,32,64]
             → 2× TransformerEncoderLayer(d=64, nhead=4, ff=128, dropout=0.1)
             → [B,32,64]
   pooling: masked-mean  (không attn)  |  attention pooling (có attn)
             → LayerNorm → v_txt [B,64]
Input
tokens [B,32] + pad-mask
Output
v_txt [B,64]

⑥ Temporal Attention (text)

💡 Cảm hứng: Additive attention (Bahdanau, Cho, Bengio, 2014) trong dịch máy — thay vì lấy 1 hidden cuối, học trọng số cho từng bước thời gian rồi tổng có trọng số (attention pooling).
Là gì
Lớp attention 1 đầu, tính điểm cho từng token của chuỗi (LSTM hoặc Transformer).
Làm gì
Cho từ khóa quan trọng ("effusion", "left lobe") trọng số cao thay vì phụ thuộc vị trí cuối câu. Có pad-mask: token PAD nhận trọng số 0.
Input
chuỗi [B,T,H] + pad-mask [B,T]
Output
context [B,H] + trọng số αₜ (để vẽ giải thích)

⑦ Projector — MLP Mapper fusion

💡 Cảm hứng: mapping network nối 2 modality — kiểu ClipCap (Mokady 2021), prefix-tuning (Li & Liang 2021), MedVInT / PMC-VQA (Zhang 2023). Trong dự án này, chính là MLP Mapper 512→768→768 nối CLIP→GPT-2 ở baseline Open_Ended_VQA_fixed.ipynb.
Là gì
MLP nhỏ chiếu vector mỗi modality về một không gian latent chung (chiều P) trước khi ghép.
Làm gì
v_img (không gian thị giác) và v_txt (không gian ngữ nghĩa) khác nhau → concat thẳng buộc decoder tự "dịch". Projector căn chỉnh 2 modality về cùng không gian → fusion dễ hơn.
Input
v_img [B,128], v_txt [B,64]
Output
z_img [B,P], z_txt [B,P] → concat [B,2P]
Khối này có trong code_references.ipynb (cờ use_projector) nhưng CHƯA có trong src/models/fusion.py (đang concat thẳng 128+64=192) — phần sẽ bổ sung vào code sau.

⑧ Fusion — Concatenation

💡 Cảm hứng: joint/early fusion trong multimodal learning — cách hợp nhất đơn giản, rẻ, dễ giải thích: nối 2 vector đặc trưng.
Là gì
Phép ghép nối 2 vector modality thành 1 vector chung.
Làm gì
Không projector: [v_img;v_txt]=[B,192]. Có projector: [z_img;z_txt]=[B,2P]. Vector này đưa xuống decoder.
Input
2 vector modality
Output
fused [B,192] hoặc [B,2P]

⑨ Gated Attention (decoder)

💡 Cảm hứng: cơ chế gating — Highway Networks (Srivastava 2015), GLU (Dauphin et al. 2017): dùng cổng sigmoid để lọc/điều tiết thông tin đi qua.
Là gì
Một cổng sigmoid học được, áp lên fused vector trước khi phân loại.
Làm gì
z' = z ⊙ σ(W·z) — mỗi chiều của fused vector được nhân hệ số 0–1, lọc bớt chiều nhiễu sau khi concat 2 modality.
fused z [B,D] → Linear(D→D) → σ → gate [B,D] (0..1)
             → z' = z ⊙ gate → [B,D]
Input
fused [B,D]
Output
fused đã lọc [B,D] (cùng chiều)

⑩ Decoder — GRU generative (sinh token-by-token)

💡 Cảm hứng: encoder–decoder generation (Sutskever seq2seq 2014; Bahdanau 2014) và MedVInT-TD / prefix-tuning cho VQA sinh. Coi VQA là bài toán sinh chuỗi có điều kiện p(y₁:T | I,q)=Π p(yₜ|y<t,I,q), KHÔNG phân loại trên answer class.
Là gì
GRU 1 lớp, hidden 128, sinh answer từng token cho tới <eos> / MAX_ANSWER_LEN.
Làm gì
Hidden khởi tạo lấy từ fusion vector qua Linear(fused→128). Mỗi bước: embedding token trước + cross-attention lên image spatial tokens & question states → GRU → Linear(128→V_answer) ra logits token kế tiếp. Train bằng teacher forcing.
prev_token_emb [B,64] + cross-attn context [B,128]
   → GRU → hidden [B,128] → Linear(128 → V_answer)
   → next-token logits [B, V_answer]     (lặp T bước → [B,T,V_answer])
<bos> → token₁ → … → token_T → <eos>
Input
decoder_input tokens + image tokens [B,256,128] + question states [B,T,64]
Output
logits [B, T, V_answer] → greedy/beam → answer string
Thay cho MLP classifier cũ: bỏ hẳn Linear(fused→128→C) + argmax→id2answer. Đây là khối generative — xem đề cương 02_de_cuong_generative_medvqa.html.

⑪ Reinforcement Learning — REINFORCE Self-Critical (SCST)

Chạy sau khi SFT xong, chỉ trên checkpoint tốt nhất (nhóm D). File: src/train/rl.py.

💡 Cảm hứng: REINFORCE / policy gradient (Williams, 1992) + Self-Critical Sequence Training (Rennie et al., CVPR 2017) — vốn dùng cho image captioning để tối ưu trực tiếp BLEU/CIDEr.

Dùng để làm gì?

Cross-entropy (SFT) tối ưu xác suất token đúng, không tối ưu trực tiếp thước đo đánh giá (EM, F1) vì chúng không khả vi (rời rạc). RL cho phép tối ưu thẳng phần thưởng theo đúng metric.

Kỹ thuật — vì sao "self-critical"

  • Policy = chính model (phân phối softmax trên C answer).
  • Mỗi bước: sample 1 answer từ phân phối + lấy greedy (argmax) làm baseline.
  • Advantage = reward(sample) − reward(greedy). Nếu sample tốt hơn greedy → đẩy xác suất lên; kém hơn → hạ xuống.
  • Baseline "self-critical" (chính greedy của model) giúp giảm variance mà không cần value network riêng.
  • Grad clip 1.0 cho ổn định.

Phần thưởng (reward)

reward = 0.5 · EM + 0.5 · token_F1   (giữa answer dự đoán và answer đúng)
# answer là "unseen" (không có trong vocab train) → reward = 0

Hàm mất mát (policy gradient)

advantage = r(sample) − r(greedy)
loss = − ( logπ(sample) · advantage ).mean()      # đẩy sample tốt, ép sample tệ
Input
ảnh + tokens (train), checkpoint SFT tốt nhất
Output
model đã fine-tune (best val EM) → checkpoint D1_scst_best.pt
Lưu ý: REINFORCE variance cao trên reward thưa → có thể không cải thiện. Đó vẫn là finding hợp lệ; nếu tệ hơn thì giữ SFT làm final. Thứ tự bắt buộc: SFT trước → RL sau.
